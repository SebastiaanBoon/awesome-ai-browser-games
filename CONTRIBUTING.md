# Contributing

Thanks for adding to Awesome AI Browser Games. This follows the [awesome list guidelines](https://github.com/sindresorhus/awesome/blob/main/pull_request_template.md) with a few rules specific to games.

## What belongs

- **Games made with AI:** browser games built with AI coding agents or models (Claude, GPT, Gemini, Cursor, Codex and so on).
- **Games with AI in the gameplay:** browser games where AI is part of what you play: LLM-driven characters or story, AI opponents, generated worlds.
- Directories, platforms, jams, tools and related lists that help people find or make either kind.

Games must be free to start, playable in a desktop or mobile browser with no download, and live right now. Self-promotion is fine if the game fits; say who you are in the PR.

## Entry format

```
- [Name](https://example.com/) - What you do in the game, one sentence, no hype words. Built with <model/tool> · <engine>.
```

- One entry per line, link first, then a space, hyphen, space.
- Start the description with a verb or noun for what the player does. Skip "amazing", "epic", "revolutionary", "best".
- End with a period.
- `Built with` is required for games in "Games Made with AI". Only claim it if you can point to a source: your own credit line, a listing tag, a commit history, or press coverage. If the model is not public, write `model not stated`.
- Engine is optional but welcome (Three.js, Phaser, PixiJS, Godot, plain Canvas, and so on).
- Games with AI in the gameplay do not need `Built with`. Say what the AI does instead.

## Rules

- Alphabetical order within each section or subsection. Ignore leading "The" when sorting.
- No duplicates. Search the list before you add.
- Use the canonical URL of the game, not a tracker, portal or shortener.
- Every link must return a live page. Parked domains, dead demos and login walls are removed.
- Put each game in one genre subsection only.
- Keep commits small: one entry or one correction per PR is easiest to review.
- Add a short PR description with the link and, for "Built with", the source.

## Removal

Entries that go offline, move behind a paywall or login, or turn out to be misdescribed are removed. If your game is listed and you want it gone, open an issue.
